# snMCP

## 概要 (Overview)
本プロジェクトは、ローカル環境において大規模言語モデル(LLM)およびベクトルデータベース(Weaviate)をDockerコンテナとしてホストし、Model Context Protocol (MCP) を通じて外部のAIクライアントから利用可能にするための統合サーバー環境です。

WSL2（Windows Subsystem for Linux 2）環境での動作を前提としており、GPU（NVIDIA/AMD）が利用可能な環境はもちろん、CPUのみの環境でも動作検証が可能なフォールバック構成を用意しています。

## リポジトリ構成 (Architecture)
このリポジトリは、複数のコンポーネントが連携して動作するように構成されています。

- `mcpServer/` : MCP (Model Context Protocol) サーバーの実装。外部クライアントとのインターフェースを担います。
- `backend/` : アプリケーションのロジック、LLMアクセス、ベクトルDB操作を処理するバックエンドです。
- `weaviate/` : ドキュメントやナレッジのベクトル検索・保存を行うベクトルデータベース環境です。
- `vllmGPU/` `vllmCPU/` : LLMをローカルで高速に推論するための vLLM 環境です。実行環境（GPU/CPU）に応じて使い分けます。
- `__envs__/` : 各種コンテナに必要な環境変数（`.env` ファイル）のテンプレートが保存されています。
- `drawio/` : システム構成図やアーキテクチャ図などの設計資料です。
- `docs/` : 各種ドキュメントが保存されています。

## 停止とクリーンアップ (Teardown)

すべてのサービスを停止する場合は、リポジトリのルートディレクトリで以下のコマンドを実行します。

```bash
docker-compose down
```
