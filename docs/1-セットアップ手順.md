# 1. セットアップ手順

本システム（snMCP）をローカル環境で構築し、動作確認を行うまでの手順を解説します。

## 1. 前提条件
- **WSL2 環境** で動作することを確認済みです。
- **AMDGPU を使用する場合**: `vllmGPU` コンテナを有効にしてください（WSL2上でのみ動作する設定になっています）。
- **NVIDIA GPU を使用する場合**: `vllmGPU` のベースイメージを `vllm-openai` に変更し、nvidia-smi などの適切な設定を行ってください（本手順では省略します）。
- **CPU 環境のみの場合**: `vllmCPU` コンテナで「回答生成用LLM」と「ベクトルDB用LLM (Embedding)」の機能を代用します。
  - 初期設定は Embedding LLM を起動するようになっています。
  - CPU環境で回答生成用LLMも動かす場合は、コンテナ内で別途 `vllm` コマンドを実行するか、設定を切り替えてください。
- LLM実行環境として、Hugging Faceのモデルをローカルホストできる `vLLM` を使用します。

---

## 2. セットアップ手順

### ステップ1: 環境変数の設定 (envs)
1. `__envs__/samples/` ディレクトリ内のファイルをコピーして、`__envs__/` 直下に配置します。
2. 必要に応じて `.env` ファイルの中身を編集してください。
    - 例: `vllmGPU.env` や `vllmCPU.env` に Hugging Face のトークン (`HF_TOKEN`) を記載します。

### ステップ2: バックエンドのシークレット設定 (secrets.yaml)
1. `backend/secrets.yaml.example` をコピーし、`backend/secrets.yaml` を作成します。
2. Weaviate の APIキー、ポート番号、LLMエンドポイントなどを自身の環境に合わせて設定します。

### ステップ3: コンテナの初回起動
docker-compose を使用して、必要なコンテナ群をビルド＆起動します。
```bash
docker-compose up -d --build
```
※ GPU環境の場合は、`docker-compose.yaml` 内の `vllm-gpu` コマンドやボリュームマウントを環境に合わせて調整してください。

### ステップ4: 言語モデルのダウンロード
1. 起動した vLLM コンテナに入ります（CPUの場合は `vllmCPU`、GPUの場合は `vllmGPU` に入ります）。
   ```bash
   docker exec -it vllmGPU /bin/bash
   ```
2. Hugging Face CLI を使用してモデルをダウンロードします（例: `google/gemma-3-1b-it`）。
   ```bash
   mkdir -p /app/vllm/models/<your-model-name>
   huggingface-cli download <model-name> --local-dir /app/vllm/models/<your-model-name>
   ```
3. ダウンロードが完了したらコンテナを抜けます。
   ```bash
   exit
   ```

### ステップ5: vLLM 起動用 Config の作成
ダウンロードしたモデルを起動できるよう、設定ファイル（YAML）を作成します。
- **CPUの場合**: `vllmCPU/configs/embeddinggemma-300m.yaml` 等を参考に、同様の場所に設定ファイル（例: `gemma-3-1b.yaml`）を作成します。

### ステップ6: 起動コマンドの更新と再起動
1. `docker-compose.yaml` 内の `vllm-gpu` または `vllm-cpu` サービスの `command` にて、作成した config ファイルを読み込むように指定します。
   ```yaml
   command: vllm serve --config /app/vllm/configs/gemma-3-1b.yaml
   ```
2. 再起動します。
   ```bash
   docker-compose up -d --build
   ```
3. ログを確認し、モデルが正しくデプロイされていることを確認します。
   ```bash
   docker logs vllmGPU
   ```
   ```text
   (APIServer pid=1) INFO:     Started server process [1]
   (APIServer pid=1) INFO:     Waiting for application startup.
   (APIServer pid=1) INFO:     Application startup complete.
   ```

## 3. 動作確認

### LLMの動作確認
1. backend コンテナに入ります。
   ```bash
   docker exec -it backend /bin/bash
   ```
2. `backend/99_test/vllm_access.py` を自身の構築環境（CPUかGPUか、ポート等）に合わせて修正します。
3. Pythonスクリプトを実行し、LLMからの返答が正しく出力されるか確認します。
   ```bash
   python 99_test/vllm_access.py
   ```
   *成功すると、LLMからの挨拶等の回答とトークン使用量のメタデータが出力されます。*

### Weaviate (ベクトルDB) の動作確認
1. 引き続き backend コンテナ内で、`backend/99_test/testDB.py` を実行します。
   ```bash
   python 99_test/testDB.py
   ```
2. 正常に実行されると、テスト用のデータがDBに書き込まれ、類似度検索（例: "boy"）の結果がメタデータと共に出力されます。
   ```text
   Weaviate is ready.
   Object(uuid=..., properties={'description': '...', 'title': '...'})
   ```
