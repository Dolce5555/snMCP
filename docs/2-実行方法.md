# 2. 実行方法 (Usage)

本ドキュメントでは、セットアップが完了した `snMCP` コアシステムを起動し、外部クライアント（CursorやClaude Desktopなど）から MCP サーバーを利用する方法について解説します。

## 1. サーバー群の起動と停止

セットアップが完了していれば、2回目以降の起動は非常にシンプルです。

### 起動方法
プロジェクトのルートディレクトリで以下のコマンドを実行し、全コンテナをバックグラウンドで起動します。
```bash
docker-compose up -d
```
起動が完了したら、vLLM コンテナ（GPUまたはCPU）が正しくモデルをサービングしているかログを確認します。
```bash
docker logs vllmGPU   # または vllmCPU
```
*`Application startup complete.` と表示されていれば、LLMの推論準備は完了しています。*

### 停止方法
```bash
docker-compose down
```
※ 追加したデータ（Weaviate の中身等）やダウンロードしたLLMのモデルまで完全に削除したい場合は `-v` を付けますが、通常は不要です。
